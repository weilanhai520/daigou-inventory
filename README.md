# 代购库存发布版

这是一个非商业使用的静态网页版本，可以发布到 Vercel、Netlify、Cloudflare Pages、GitHub Pages 等静态托管平台。

## 使用方式

- 访客打开页面后只能查看在库商品、照片、库存和卖出价格。
- 管理员点击“管理员入口”，输入密码后可以入库、出库、查看明细、导出表格、删除商品和清空数据。
- 默认管理员密码在 `app.js` 里：

```js
const ADMIN_PASSWORD = "admin123";
```

发布前建议把它改成你自己的密码。

## 发布文件

只需要上传这几个文件：

- `index.html`
- `styles.css`
- `app.js`
- `README.md` 可选

## 重要说明

当前版本是静态发布版，数据保存在每个浏览器本地。也就是说，你在自己电脑录入的数据，不会自动同步到朋友手机上。

如果后续要让朋友登录后看到同一套实时库存，需要继续接入云数据库和真正的账号系统，例如 Supabase 或 Firebase。
